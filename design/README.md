# Design history

The PNG files in this directory are early concepts generated with ChatGPT's image tool. They contain sample data and are not screenshots of the app. The saved prompts document the design exploration.

The current implementation uses a WPF window with per-pixel transparency, automatically sized text, weekly-first readings, and no pin button. Unlike the early frosted-glass concept, it does not blur the backdrop.

Current product screenshots are in `docs/assets/` and are rendered from the real controls using `--screenshots`.
