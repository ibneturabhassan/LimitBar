# Changelog

## 0.1.0-beta.1

Initial open-source Windows beta.

- Codex and experimental Claude subscription readings.
- Two stacked taskbar lines: weekly, optional session, and reset countdown.
- Translucent hover card with automatically sized text.
- Missing sessions are omitted; failed readings are explicitly stale.
- Refresh scheduling, reset checks, and opt-in notification tips/startup.
- Self-contained Windows x64 installer and portable ZIP.
- Offline checks, Windows CI, setup documentation, and sample-data screenshots.

Known limits: unsigned binaries, primary horizontal taskbar only, external CLI sign-in, experimental Claude endpoint, no automatic updater, and no native ARM64 testing.
